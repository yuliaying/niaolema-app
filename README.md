# 尿了吗 · 排尿健康记录

> 随手一记，看懂自己的规律。

一个**单文件、零依赖、可离线**使用的排尿健康记录应用。用浏览器打开即用，也可以「添加到主屏幕」当原生 App 用。所有数据只保存在你自己的设备上，不会上传到任何服务器。

**在线体验**：https://yuliaying.github.io/niaolema-app/ （GitHub Pages，可直接在微信中打开）

备用地址：https://niaolema-app.app.workbuddy.host/ （该域名会拦截微信内置浏览器）

---

## 功能

- **一键记录**：首页大圆环点一下就记下当前时间，圆环同时显示当日目标完成进度；长按弹出详细记录
- **详细记录**：时间（支持补录）、大概尿量、尿液颜色 5 级比色、尿急程度、尿痛标记、备注
- **饮水记录**：「喝了一杯水」快捷按钮，单杯容量可在设置里调整
- **统计**：近 7 天 / 30 天切换 —— 日均次数、日均尿量、单次平均量、平均间隔、夜尿次数
- **图表**：每日趋势柱状图、24 小时时段分布、尿色分布（纯手写 SVG，无图表库依赖）
- **健康提示**：根据记录数据自动给出观察建议（尿频、夜尿 ≥2 次、尿色偏深提示缺水、尿痛建议就医等），并附免责声明
- **数据管理**：JSON 导出备份 / 导入恢复 / 清空；可一键填充 30 天示例数据预览统计效果
- **PWA**：支持安装到桌面、离线使用（Service Worker 缓存应用外壳）

## 快速开始

**方式一：直接打开**

双击 `index.html` 即可使用（记录、统计、导出全部正常）。

**方式二：本地起服务（推荐，可完整体验 PWA / 离线能力）**

```bash
cd niaolema-repo
python -m http.server 8777
# 浏览器访问 http://127.0.0.1:8777
```

> Service Worker（离线缓存、安装到桌面）必须在 `http://localhost` 或 `https://` 下才生效。

## 安装到手机

- **安卓**：浏览器打开线上链接 → 设置页点「📲 安装到手机桌面」
- **iPhone**：必须用 **Safari** 打开 → 底部分享按钮 ⬆️ → 「添加到主屏幕」

安装后桌面有独立图标、全屏无地址栏，断网也能继续记录。

## 重新生成分享物料

改了自己的域名后，二维码和分享卡片需要重做：

```bash
pip install qrcode pillow

# 默认链接是线上演示地址，可覆盖
SITE_URL=https://你的域名/ python tools/make-share-assets.py
```

脚本会覆盖 `assets/qr.png` 与 `assets/share-card.png`。

> 踩坑记录：二维码定位眼的圆角半径必须 ≤ 1 个模块宽度（本例 box_size=20px，取 20px 安全，32px 会切掉角部关键像素导致部分解码器失败）。中心 logo 面积控制在 23.5% 以内，配合 H 级纠错（30% 冗余）。验证方式：`opencv` 与 `zxing-cpp` 双解码器交叉验证，并做缩小测试。

## 数据与隐私

- 数据保存在浏览器 `localStorage`，key 为 `niaolema.v1`（结构：`{ version, records[], drinks[], settings }`）
- **全程不联网、不上传任何数据**，因此作为单机应用无需工信部 App 备案
- 换手机 / 清浏览器数据前，请先在设置页「导出数据」备份

## 部署说明

任意静态托管平台都能直接部署（本仓库根目录即为站点根目录）：GitHub Pages、Vercel、Netlify、腾讯 EdgeOne Pages、对象存储等。

> 注意：演示用的 `workbuddy.host` 域名会拦截微信内置浏览器（微信内打开会提示「请在浏览器中打开」）。如果需要朋友在微信里直接打开，请部署到其他平台。

## 免责声明

应用内的健康提示基于公开的一般性参考范围自动生成，**仅供自我观察参考，不构成任何医疗诊断或建议**。如有尿频、尿急、尿痛、血尿等不适，请及时就医。
